HP-Unix의 SybaseIQ 16.0환경(이하 ASIS)에서 운영되는 ADW의 데이터를 Linux의 SybaseIQ 16.2환경(이하 TOBE)으로 이관하는 자바배치 프로그램을 개발해야 합니다.

테이블의 갯수는 13000개, 데이터싸이즈는 250TB 이며, ASIS와 TOBE는 동일한 네트워크환경에서 공유볼륨(50TB)를 이용해서 데이터를 이관합니다.
배치이관담당자들이 추출대상 테이블의 row건수, 컬럼건수, 추출 파일의 크기, 테이블이 Blob컬럼을 포함여부 등의 테이블의 특성을 분석하여 배치그룹 정의와 스케줄 배정을 할 것입니다.
배정된 배치그룹과 배치스케줄은 GODIS웹에 등록하여, GODIS웹 프레임워크에 설정된 순차실행/멀티스레드 방식으로 실행되는 환경입니다.

개발하려는 "자바배치 프로그램"은 
- pure java방식으로
- SQL 관리는 마이바티스 사용
- 프로그램 로깅을 위한 최신기술 적용(로그 레벨은 4단계로 프로퍼티에서 읽어서 설정)
- 불필요한 spring F/W, 히카리(connection pool)등의 사용은 지양하고 간결하게
- java connection은 ASIS, TOBE, GODIS웹(mariaDB) 용의 3개만 사용
- shell에서 java를 호출하여 실행하는 구조
- shell에 전달할 파라미터는 3가지 배치실행차수, 배치TASK_ID, 배치실행자(default:SYSTEM)
- java 프로그램에서 파라메터인 배치TASK_ID를 가지고 GODIS웹(mariaDB)에서 배치에 필요한 정보를 추출해서 실행SQL을 생성한다.

- 이관대상 테이블 정보관리 : 테이블정보와 배치그룹(배치Task_ID) 관리 
- 이관대상 테이블의 컬럼정보관리: 추출컬럼의 (합계/평균/최소/최대)검증용 값 추출, 적재컬럼의 (합계/평균/최소/최대)검증용 값 추출

- 데이터적재를 위한 java 프로그램은 4단계로 구성된다
- 1단계 ASIS에서 테이블 데이터 추출하여 공유볼륨에 파일로 저장(sybaseIQ에서 제공하는 파일저장 기능 이용)
- 2단계 ASIS에서 추출한 데이터 건수/합계/평균/최소/최대 추출
- 3단계 ASIS에서 추출하여 저장된 파일을 TOBE로 적재(sybaseIQ에서 제공하는 Load기능이용)하고 적재성공하면 파일 삭제
- 4단계 TOBE로 적재한 데이터 건수/합계/평균/최소/최대 추출
==> 단 2단계/4단계의 검증대상은 GODIS웹(mariaDB) 설정된 컬럼을 대상으로 산출한다.
