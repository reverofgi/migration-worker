# [Request] Sybase IQ 대용량 데이터 이관용 경량 Java 배치 프로그램 개발

당신은 레거시 마이그레이션 및 대용량 데이터 처리 전문 시니어 자바/DBA 엔지니어입니다.
아래 명시된 아키텍처, 기술 스택, 실행 프로세스 및 제약사항을 준수하여 **Pure Java 기반 대용량 이관 배치 프로그램**의 전체 소스 코드와 설정을 작성해 주세요.

---

## 1. 프로젝트 개요 및 환경
* **이관 목적**: HP-Unix Sybase IQ 16.0(AS-IS)에서 Linux Sybase IQ 16.2(TO-BE)로 ADW 데이터 이관
* **데이터 규모**: 테이블 약 13,000개, 총 데이터 약 250TB
* **인프라 환경**: AS-IS와 TO-BE가 동일 네트워크에서 **50TB 크기의 공유 볼륨(NFS/공유스토리지)**을 매개체로 데이터 이관
* **실행 환경**: GODIS 웹(MariaDB 기반 배치 관리 프레임워크)에서 스케줄링/멀티스레드로 Shell Script를 호출하여 실행

---

## 2. 기술 스택 및 핵심 제약사항
1. **Pure Java (Lightweight)**:
   * Spring Framework, Spring Batch, HikariCP 등 무거운 외부 프레임워크 사용을 배제하고 단독 실행 가능한 경량 Java 애플리케이션으로 작성
2. **SQL 관리**:
   * **MyBatis (SqlSessionFactory/XML)**를 사용하여 정적/동적 SQL 분리 및 관리
3. **Connection 관리 (총 3개 커넥션)**:
   * 커넥션 풀을 쓰지 않고 배치 실행 시 필요한 3개 Connection을 명시적으로 생성/관리 후 종료
     - `ASIS Connection`: Sybase IQ 16.0 (Extract & Validation)
     - `TOBE Connection`: Sybase IQ 16.2 (Load & Validation)
     - `META Connection`: GODIS MariaDB (Task 메타데이터 조회 및 실행 결과/검증값 업데이트)
4. **로깅 (Logging)**:
   * SLF4J + Logback 적용
   * 외부 설정 파일(`batch.properties` 등)에서 4단계 로그 레벨(DEBUG, INFO, WARN, ERROR)을 동적으로 읽어 적용
5. **Sybase IQ 특화 기능 사용**:
   * 추출: Sybase IQ 네이티브 추출 기능 (`TEMP_EXTRACT_OPTIONS` 설정 후 추출)
   * 적재: Sybase IQ 네이티브 적재 기능 (`LOAD TABLE` 구문)
   * 파일 관리: 공유 볼륨(50TB) 용량 한계를 감안하여 **적재 성공 즉시 추출 임시 파일 자동 삭제**

---

## 3. 프로그램 실행 인터페이스 (CLI Arguments)
Shell Script에서 `java -jar BatchRunner.jar <arg1> <arg2> <arg3>` 형태로 호출:
* `args[0]` : **배치실행차수** (`EXEC_SEQ`, 필수)
* `args[1]` : **배치 TASK_ID** (`TASK_ID`, 필수)
* `args[2]` : **배치실행자** (`EXEC_USER`, 선택, Default: `SYSTEM`)

---

## 4. 상세 처리 프로세스 (4-Step Pipeline)

### [Step 0: 초기화 및 메타데이터 조회]
* MariaDB(GODIS)에서 전달받은 `TASK_ID`를 기반으로 배치 작업 정보 조회:
  - 대상 테이블명(AS-IS / TO-BE), 스키마 정보, Blob 컬럼 포함 여부
  - 공유 볼륨 내 추출 파일 저장 경로 및 파일명 규칙
  - 검증 대상 컬럼 목록 및 집계 함수 유형 (SUM, AVG, MIN, MAX 등)
* MariaDB에 배치 상태를 `RUNNING`으로 기록.

### [Step 1: AS-IS 데이터 추출 (Extract)]
* AS-IS Sybase IQ에 접속하여 테이블 데이터를 공유 볼륨 경로로 파일 추출
* Sybase IQ `SET TEMPORARY OPTION TEMP_EXTRACT_...` 옵션 제어 및 SELECT 추출 쿼리 실행

### [Step 2: AS-IS 데이터 검증값 산출 (AS-IS Verify)]
* AS-IS DB에서 총 건수(`COUNT(*)`) 및 MariaDB에 설정된 검증 대상 컬럼의 집계값(`SUM`, `AVG`, `MIN`, `MAX`) 쿼리 동적 생성 및 실행
* 산출된 검증값을 MariaDB 작업 로그 테이블에 저장

### [Step 3: TO-BE 데이터 적재 (Load) 및 파일 정리]
* TO-BE Sybase IQ에 접속하여 공유 볼륨의 파일을 읽어 `LOAD TABLE ...` 구문 실행
* **적재 성공 확인 시**: 공유 볼륨에 생성되었던 추출 파일 즉시 삭제 (50TB 볼륨 순환을 위해 필수)
* **적재 실패 시**: 오류 로깅, 파일 보존(원인 분석용), 상태 `FAILED` 처리 및 프로세스 중단

### [Step 4: TO-BE 데이터 검증 및 최종 완료 (TO-BE Verify & Finish)]
* TO-BE DB에서 동일하게 총 건수 및 검증 대상 컬럼의 집계값 산출
* AS-IS 검증값 vs TO-BE 검증값 일치 여부 비교
* MariaDB에 최종 상태(`SUCCESS` 또는 `VERIFY_MISMATCH`), 실행 시간, 검증 결과 갱신

## 5. 요청 산출물

다음 항목들이 포함된 완전한 코드베이스 구조와 구현 소스를 제시해 주세요.

1. **프로젝트 디렉토리 구조** (Maven 또는 Gradle 기반 표준 구조)
2. **설정 파일**:
   - `batch.properties` (DB 접속정보 3종, 로그 레벨, 공유 볼륨 기본 경로 등)
   - `logback.xml` (외부 프로퍼티와 연동된 로깅 설정)
   - `mybatis-config.xml` (MyBatis 기본 설정)
3. **MyBatis XML 매퍼**:
   - `MetaMapper.xml`: GODIS MariaDB용 (작업조회, 상태변경, 검증결과 저장)
   - `AsisMapper.xml`: Sybase IQ 추출 및 ASIS 검증 쿼리
   - `TobeMapper.xml`: Sybase IQ Load 및 TOBE 검증 쿼리
4. **Java 소스 코드**:
   - `Main.java` (인자 파싱, 팩토리 초기화, 배치 오케스트레이션)
   - `ConnectionFactory.java` (ASIS, TOBE, MariaDB의 SqlSessionFactory/Connection 제어)
   - `BatchService.java` (4단계 파이프라인 비즈니스 로직 및 트랜잭션/예외 처리)
   - `VerificationService.java` (동적 검증 쿼리 생성 및 비교 로직)
   - `FileUtil.java` (공유볼륨 파일 존재 확인 및 적재 후 안전한 파일 삭제)
5. **Shell 실행 스크립트 샘플** (`run_batch.sh`): 파라미터 전달 및 Exit Code 처리 포함
