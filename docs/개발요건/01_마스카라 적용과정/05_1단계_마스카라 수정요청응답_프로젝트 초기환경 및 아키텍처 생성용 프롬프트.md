# [Request] Sybase IQ 대용량 데이터 이관용 경량 Java 배치 프로그램 개발

당신은 대용량 데이터 마이그레이션 및 고성능 백엔드 아키텍처 전문 시니어 Java/DBA 엔지니어입니다.
아래 명시된 인프라 환경, 메타데이터 테이블 스키마 규칙, 기술 스택 및 구체적인 클래스 아키텍처를 준수하여 **Pure Java 기반 Sybase IQ 대용량 이관 배치 프로그램**의 전체 소스 코드와 설정을 작성해 주세요.

---

## 1. 프로젝트 개요 및 환경
* **이관 목적**: HP-Unix Sybase IQ 16.0(AS-IS)에서 Linux Sybase IQ 16.2(TO-BE)로 ADW 데이터 이관
* **데이터 규모**: 테이블 약 13,000개, 총 데이터 약 250TB
* **인프라 환경**: AS-IS와 TO-BE가 동일 네트워크에서 **50TB 크기의 공유 볼륨(NFS/공유스토리지)**을 매개체로 데이터 이관
* **실행 환경**: GODIS 웹(MariaDB 기반 배치 관리 프레임워크)에서 스케줄링/멀티스레드로 Shell Script를 호출하여 실행
* **특이 사항**: AS-IS와 TO-BE의 대상 테이블/컬럼 구조는 동일하며, 단일 메타데이터 세트로 관리됨

---

## 2. 기술 스택 및 핵심 제약사항
1. **Pure Java (Lightweight)**:
   * Spring Framework, Spring Batch, HikariCP 등 무거운 프레임워크를 일체 배제하고 독립 실행 가능한 경량 Java 애플리케이션으로 작성
2. **동적 프로퍼티 관리 (No Local Property File)**:
   * 배포/실행에 필요한 모든 환경설정(DB 접속정보, 경로, 로그레벨 등)은 **MariaDB의 공통코드 테이블(`GPCL_CM_CD_VAL`)**에서 동적으로 조회하여 인메모리에 바인딩
3. **SQL 관리**:
   * **MyBatis (SqlSessionFactory/XML)**를 사용하여 정적/동적 SQL 분리 및 실행
4. **Connection 관리 (총 3개 커넥션)**:
   * 외부 Connection Pool 라이브러리 없이 작업 주기 동안 필요한 3개 Connection을 명시적으로 제어/종료
     - `META Connection`: GODIS MariaDB (설정 로드, 메타데이터 조회, 상태 및 검증 결과 기록)
     - `ASIS Connection`: Sybase IQ 16.0 (데이터 추출 및 ASIS 데이터 검증)
     - `TOBE Connection`: Sybase IQ 16.2 (데이터 적재 및 TOBE 데이터 검증)
5. **로깅 (Logging)**:
   * SLF4J + Logback 적용
   * MariaDB 공통코드에서 읽어온 로그 레벨(DEBUG, INFO, WARN, ERROR)을 런타임에 동적으로 로거에 반영
6. **Sybase IQ 특화 기능 및 스토리지 관리**:
   * 추출: Sybase IQ `TEMP_EXTRACT_OPTIONS` 기반 파일 언로드
   * 적재: Sybase IQ `LOAD TABLE` 구문 기반 고속 파일 로드
   * 공간 관리: 공유 볼륨(50TB) 순환을 위해 **적재 완료 즉시 공유 볼륨의 추출 파일 삭제**

---

## 3. 프로그램 실행 인터페이스 (CLI Arguments)
Shell Script에서 `java -cp ... com.migration.MigrationWorkerApplication <arg1> <arg2> <arg3>` 형태로 호출:
* `args[0]` : **배치실행차수** (`EXEC_SEQ`, 필수)
* `args[1]` : **배치 TASK_ID** (`TASK_ID`, 필수)
* `args[2]` : **배치실행자** (`EXEC_USER`, 선택, Default: `SYSTEM`)

---

## 4. 메타데이터 테이블 구조 및 처리 프로세스 (4-Step Pipeline)

### [메타데이터 테이블 참조 규칙 (MariaDB)]
1. **공통코드 테이블 (`GPCL_CM_CD_VAL`)**:
   * `GRP_CD_ID = 'MIGRATION_PROPERTIES'` 조건으로 조회
   * AS-IS / TO-BE / MariaDB JDBC 접속 정보 (URL, User, Password, Driver)
   * 로그 레벨 (LOG_LEVEL)
   * 공유 볼륨 내 추출 파일 저장 기본 경로 및 파일명 생성 규칙
   * Blob 컬럼 임시 저장 경로 등
2. **이관 대상 테이블 정보 (`GPCL_MIG_TABLE`)**:
   * `TASK_ID`로 매핑된 테이블명, 스키마, 옵션, 파일 분할 여부, Blob 포함 여부 등
3. **이관 검증 대상 컬럼 정보 (`GPCL_MIG_VRF_TARGET`)**:
   * 대상 테이블의 검증 컬럼 목록 및 적용 함수 (COUNT, SUM, AVG, MIN, MAX 등)

---

### [상세 4단계 파이프라인]

* **[Step 0: 초기화 및 메타데이터 로드]**
  - MariaDB 최소 접속 정보로 `GPCL_CM_CD_VAL`에서 전체 동작 환경설정 로드 및 `LogUtil`을 통해 로그 레벨 동적 세팅
  - `ConnectionFactory` 초기화 (ASIS, TOBE 커넥션 빌드)
  - `GPCL_MIG_TABLE` 및 `GPCL_MIG_VRF_TARGET`에서 해당 `TASK_ID`의 테이블 및 검증 컬럼 메타정보 조회
  - MariaDB에 작업 상태를 `RUNNING`으로 기록

* **[Step 1: AS-IS 데이터 추출 (Extract)]**
  - `SybaseIQUnloadWorker` 및 `SybaseIQSqlBuilder`를 통해 AS-IS IQ 네이티브 언로드 옵션 세팅 및 SELECT 쿼리 실행
  - 공유 볼륨 경로에 지정된 명명 규칙으로 데이터 파일 저장

* **[Step 2: AS-IS 데이터 검증값 산출 (AS-IS Verify)]**
  - `MigrationValidator`가 `GPCL_MIG_VRF_TARGET`에 정의된 컬럼별 집계 쿼리(COUNT, SUM, AVG, MIN, MAX)를 동적으로 생성하여 AS-IS DB에서 실행
  - 추출된 원천 검증값을 MariaDB 작업 로그/검증 테이블에 insert 기록

* **[Step 3: TO-BE 데이터 적재 (Load) 및 파일 정리]**
  - `SybaseIQLoadWorker`를 통해 TO-BE IQ의 `LOAD TABLE` 구문 실행
  - **적재 성공 확인 시**: `FileUtil`을 호출하여 공유 볼륨의 추출 파일 즉시 삭제 (50TB 볼륨 순환)
  - **적재 실패 시**: 상세 에러 로깅, 파일 보존, 작업 상태 `FAILED` 갱신 후 비정상 종료 (Exit Code != 0)

* **[Step 4: TO-BE 데이터 검증 및 최종 판정 (TO-BE Verify & Finish)]**
  - TO-BE DB에서 Step 2와 동일한 검증 집계 쿼리 실행하여 update 실행(키값: 실행회차, 테이블명, 실행순서, 컬럼명) 
  - `MigrationValidator`가 AS-IS 검증값과 TO-BE 검증값의 일치 여부를 정밀 비교
  - 불일치 시 `VERIFY_MISMATCH`, 일치 시 `SUCCESS`로 MariaDB 갱신 및 소요시간, 처리건수 최종 기록

---

## 5. 요청 산출물

다음 명시된 클래스 및 매퍼 구성을 바탕으로 프로덕션 레벨의 전체 소스 코드를 구현해 주세요.

### 1. MyBatis XML 매퍼
* `MetaMapper.xml`:
  - `GPCL_CM_CD_VAL` 조회
  - `GPCL_MIG_TABLE`, `GPCL_MIG_VRF_TARGET` 조회
  - 배치 작업 이력/상태 변경 및 검증 결과 INSERT/UPDATE
* `SybaseIQMapper.xml` (ASIS/TOBE 공용):
  - Sybase IQ 추출 옵션 세팅/해제 및 Unload 트리거
  - `LOAD TABLE` 구문 실행
  - 건수 및 동적 컬럼 검증 쿼리 (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)

### 2. Java 소스 코드
* **`MigrationWorkerApplication.java`**: 메인 진입점. CLI 인자 파싱(`EXEC_SEQ`, `TASK_ID`, `EXEC_USER`), 프로세스 라이프사이클 관리, System Exit Code 제어
* **`MigrationWorker.java`**: 전체 4단계(Step 0 ~ Step 4) 파이프라인 제어, 에러 핸들링 및 상태 동기화 오케스트레이터
* **`ConnectionFactory.java`**: MariaDB 공통코드에서 읽어온 정보를 기반으로 ASIS, TOBE, META용 `SqlSessionFactory` 및 `Connection`을 생성/제공/반환하는 단일 팩토리
* **`SybaseIQUnloadWorker.java`**: AS-IS Sybase IQ 16.0 전용 Unload(추출) 로직 구현 (`TEMP_EXTRACT_OPTIONS` 핸들링)
* **`SybaseIQLoadWorker.java`**: TO-BE Sybase IQ 16.2 전용 `LOAD TABLE` 적재 로직 구현
* **`MigrationValidator.java`**: `GPCL_MIG_VRF_TARGET` 기반 검증 쿼리 실행 및 AS-IS vs TO-BE 검증값 정밀 비교 판정 로직
* **`SybaseIQSqlBuilder.java`**: Sybase IQ 네이티브 Unload/Load DDL 및 동적 집계/검증 SQL 빌더
* **`FileUtil.java`**: 공유 볼륨 파일 존재 여부, 파일 크기 체크, 적재 완료 후 안전한 파일 삭제 로직
* **`LogUtil.java`**: MariaDB 프로퍼티에서 조회한 로그 레벨을 Logback 콘텍스트에 동적으로 적용하는 유틸리티
* **`SqlUtil.java`**: 리소스 해제(AutoCloseable), 예외 래핑 등 공통 JDBC/MyBatis 유틸리티

### 3. Shell 실행 스크립트 (`run_migration.sh`)
* 인자 전달, Java Classpath 설정, JVM 옵션(메모리 설정), Exit Code 수신 및 GODIS 반환 스크립트 예시
